# Data

Raw data is **not** committed (files are large).

1. Go to https://moneypuck.com/data.htm
2. Under **Shot Data**, download one season (e.g. the most recent full regular season)
3. Unzip the CSV into `data/raw/`

Check MoneyPuck's data dictionary on the same page for column definitions. Data © MoneyPuck.com, used for non-commercial purposes with credit.
